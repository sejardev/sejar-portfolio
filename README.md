# Sejar's portfolio

A responsive single-page developer portfolio built with HTML, CSS, and JavaScript.

The site introduces Sejar as an aspiring full-stack developer, lists his skills, and features the [AdemiTrade website](https://ademitrade.com).

## View the site

Visit [sejardev.github.io/sejar-portfolio](https://sejardev.github.io/sejar-portfolio/).

## Run locally

Open `index.html` in a browser. No build step is needed.

The portrait area is a placeholder until Sejar chooses a photo. A CV link will be added once he supplies a CV.
